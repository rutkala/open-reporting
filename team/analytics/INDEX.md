# Analytics Knowledge Base

Agent reference library for analytical thinking, visualization standards, and domain-specific analytics conventions.

**When to use:** Read the relevant module at the start of `/domain-brief` and `/plan` phases — before designing any chart, analysis, or dashboard layout. Do not load all files every session; load only what is relevant to the current task.

---

## Modules

| File | Covers | Read when |
|------|--------|-----------|
| [visualization-guide.md](visualization-guide.md) | Chart type selection, dual-axis patterns, color semantics, reference lines | Before designing any chart or dashboard layout |
| [analytical-thinking.md](analytical-thinking.md) | How to move from data to insight, insight hierarchy, analytical moves | Before structuring any analysis or insight strip |
| [domains/public-finance.md](domains/public-finance.md) | Fiscal KPIs, SGP rules, canonical chart patterns, Polish benchmarks | Before any public finance dashboard or chart work |

---

## How to add a new domain module

1. Create `team/analytics/domains/{domain-slug}.md`
2. Add a row to the table above
3. Create a sub-issue under OR-116 to track the work

Domain modules are added on a rolling basis — one per domain, before that domain's dashboard work starts.
