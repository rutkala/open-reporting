# UX/UI Design Component

## Produces
- UX/UI Design (layout, visual mappings, UI components)

## Internal DAG
See `dag/ux-ui-design.yaml`

## Step Instructions

### Step 1: Layout Design
Design the overall layout structure.

**Actions:**
- Define header with title and metadata
- Position filters at top
- Define topic groups
- Define footer with sources

**Output:** Layout Design

---

### Step 2: Topic Grouping
Group related KPIs into logical sections.

**Actions:**
- Group related KPIs
- Define section structure
- Prioritize content

**Output:** Topic Groups

---

### Step 3: Chart Selection
Select appropriate chart types for each KPI.

**Actions:**
- Select bar charts for comparisons
- Select line charts for trends
- Select tables for detailed data
- Select maps for geographic data

**Output:** Chart Selections

---

### Step 4: Interaction Flow
Define how filters interact with charts.

**Actions:**
- Define filter-to-chart flow
- Document interactions
- Test edge cases

**Output:** Interaction Flow

---

### Step 5: Review
Review the design for completeness.

**Actions:**
- Verify cognitive load (max 5 charts per page)
- Verify chart types are appropriate
- Verify layout is clean

**Output:** Review Comments

---

### Step 6: Finalize
Finalize the UX/UI design.

**Actions:**
- Incorporate review feedback
- Finalize documentation

**Output:** Final UX/UI Design

---

## Input Requirements
- Requirements Document
- Architecture Design

## Output
- UX/UI Design
