# Power BI Community Data Stories Gallery — annotation

## What this source teaches

The Power BI community Data Stories Gallery is a practitioner showcase rather than a curated editorial selection. Its value is different from Eurostat or Datawrapper Academy: it shows what intermediate-to-advanced Power BI builders actually produce when given a domain problem and the full toolkit. The gallery reveals both strong patterns (well-composed scenario simulators, consistent dark-theme conventions) and anti-patterns (overuse of gauges, colour oversaturation). Reading it critically produces sharper instincts about what community-standard Power BI looks like versus what professional-grade reporting looks like.

## Key patterns documented

- **Dark background as a dominant aesthetic choice** — Two of the four captured dashboards use very dark backgrounds (near-black or dark navy). This is a community-standard "pro dashboard" aesthetic in Power BI. The Global Terrorism Desk uses pure black with red accents; the Washington PHEV dashboard uses a dark amber-on-near-black palette. This aesthetic reads as analytical/intelligence in intent, but it reduces readability of fine text and makes gridlines invisible — the WCAG contrast requirements are often violated in dark-mode Power BI reports. The light-theme Manufacturing dashboard (white background, green accent) is notably more readable in the captured image, demonstrating that light themes serve reference/analysis use cases better than dark themes. `![](images/global-terrorism-intelligence-desk.png)` `![](images/washington-phev-analysis.jpg)`

- **Scenario simulator as a recurring dashboard type** — Two of the four captured reports feature an interactive scenario simulator: UK Rail (refund policy + price adjustment) and Manufacturing (operator efficiency + cost parameters). Both share the same structural pattern: numeric input sliders at the top → KPI output cards in the middle → time-series chart at the bottom showing actual vs simulated comparison. This "what-if" dashboard type is common in Power BI because slicers and parameter tables make it technically easy. The dual-line chart (actual=solid, simulated=dashed) encoding is consistent across both examples. `![](images/uk-rail-scenario-simulator.png)` `![](images/manufacturing-scenario-simulator.png)`

- **KPI card row as mandatory first element** — Every captured dashboard places a KPI summary row immediately below the title bar. In the PHEV dashboard, four cards show total vehicles registered, top manufacturer, average model year, and average electric range — these are the "what is this about" anchors before any chart is viewed. In the terrorism desk, three pre-attentive highlights (highest risk nation, most active group, fatality rate) serve the same function. This pattern matches the F-pattern layout principle documented in the PencilAndPaper reference (Wave 1).

- **Map as geography anchor** — Both the terrorism desk and the PHEV dashboard use a geographic map as their largest single visual element. The terrorism desk uses a world bubble map (circles sized by casualty volume, coloured red). The PHEV dashboard uses a Bing map tile with clustered circle markers showing registration counts by county. In both cases, the map anchors geographic intuition before any numerical deep-dive. For the public_finance dashboard, a Poland-level regional choropleth (voivodeship level) would serve this same anchor function if geographic breakdown is part of the product vision.

- **Waterfall bar for fiscal decomposition** — The Manufacturing dashboard's "Downtime Cost Reduction Breakdown" uses a waterfall-style bar chart: Current Total Cost → Cost Avoided (negative, red) → Residual Cost. This is the same chart type recommended by the FT Visual Vocabulary (Wave 1) for budget flow decomposition. Seeing it used in a community Power BI report confirms it is within practical reach using standard Power BI visual library (via a waterfall visual or a calculated field approach with a grouped bar).

- **Semi-circular gauge as efficiency indicator** — The Manufacturing dashboard uses a large semi-circular gauge showing 82.51% efficiency against a 70% target. This visual is visually prominent but informationally thin — it encodes a single value against a single target, requiring a large canvas footprint. The same information would be more compact as a KPI card with a delta indicator. Gauges are effective for real-time monitoring (think: speedometer) but wasteful in reference/analysis dashboards.

## Notable visual examples

**Global Terrorism Intelligence Desk** (`images/global-terrorism-intelligence-desk.png`) — Black background, red bubble world map. Three KPI callouts at the top in large bold text: "Afghanistan" (highest risk), "Islamic State of Iraq and the Levant (ISIL)" (most active), "3.03" fatality rate. The left sidebar uses icon-only navigation (home, target, map, book). The overall aesthetic is designed to communicate threat and urgency — the colour choices (red on black) are semantically intentional. This would be inappropriate for a public finance context but demonstrates how colour + background together create a specific emotional register.

**Washington PHEV Analysis** (`images/washington-phev-analysis.jpg`) — Dark amber-on-near-black palette. Four KPI cards across the top, then a 3-panel lower section: map (left), donut + data table (centre), line chart + horizontal bar chart (right). The donut chart (57% eligible, 43% not eligible) is the weakest element — part-to-whole with only two categories is always better served by a single KPI card with a progress bar. The horizontal bar chart (market by manufacturer) is the strongest element — sorted by value descending, value labels on bar ends, tight spacing.

**UK Rail Scenario Simulator** (`images/uk-rail-scenario-simulator.png`) — Dark navy, two-panel layout. The dual line chart at bottom-right (actual vs simulated revenue, Jan-Apr) uses solid vs dashed lines to encode actual vs simulated — this is the correct encoding for actual/forecast pairs. The horizontal bar chart (affected journeys by month) uses a single-hue blue, value-labelled, clean. The KPI cards in the simulation outputs show delta values (£1,857 refund risk, £23,630 saving) with clear currency formatting.

## Relevance to public-finance dashboards

The scenario simulator pattern (slider inputs → KPI output → actual vs simulated comparison chart) has direct application for public finance "what-if" analysis — e.g., "if Poland's deficit improves by X%, where does it land relative to the SGP threshold?" The UK Rail waterfall for cost decomposition maps onto fiscal decomposition (structural vs cyclical deficit, revenue vs expenditure contribution to balance change). Negative lessons: avoid dark backgrounds for analytical reports (contrast and readability suffer); avoid gauges where a KPI card is sufficient. The community gallery also reveals that Power BI's standard visual library already contains the chart types needed — custom visuals are rarely necessary.
