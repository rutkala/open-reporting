# NNG — Progressive Disclosure + Information Scent (paired articles)

## Article 1: Progressive Disclosure

Jakob Nielsen | December 3, 2006 | https://www.nngroup.com/articles/progressive-disclosure/

**Summary:** Progressive disclosure defers advanced or rarely used features to a secondary screen, making applications easier to learn and less error-prone.

### Introduction

Interaction designers face a dilemma: users want power and features, but also simplicity. Progressive disclosure is one of the best ways to satisfy both of these conflicting requirements:

1. Initially, show users only a few of the most important options
2. Offer a larger set of specialized options upon request — disclose these secondary features only if a user asks for them

The print dialog box is the classic example: basic options on the first screen, advanced options behind an "Advanced" button.

### Applications vs. Websites

Progressive disclosure has long been one of application design's primary guidelines. Websites have grown so complex that it is a good idea for many information-rich sites as well. Deferring secondary material is also a key guideline for mobile design.

Hypertext provides a simple implementation of progressive disclosure: higher-level pages contain higher-level concepts and simplified descriptions, and lower-level pages fill in the details.

### Benefits of Progressive Disclosure

In a system designed with progressive disclosure, the very fact that something appears on the initial display tells users that it's important.

- For novice users: helps prioritize attention; helps avoid mistakes
- For advanced users: saves them from scanning past features they rarely use

Progressive disclosure improves 3 of usability's 5 components: learnability, efficiency of use, and error rate.

### Usability Criteria for Progressive Disclosure

Two things you must get right:

1. **The right split between initial and secondary features.** Disclose everything users frequently need up front. The primary list can't contain too many options or you'll fail to focus users' attention on truly important issues.

2. **It must be obvious how users progress from the primary to the secondary disclosure levels.** Make the mechanics simple. Label the button or link in a way that sets clear expectations.

In practice, designs that go beyond 2 disclosure levels typically have low usability because users often get lost moving between levels.

### Staged Disclosure: One Step at a Time

Staged disclosure is a variant in which users step through a linear sequence of options (Wizards are the classic example). Key differences:

| Aspect | Progressive Disclosure | Staged Disclosure |
|--------|------------------------|-------------------|
| Initial display | Core features | Features accessed first in the task sequence |
| Do users access subsequent displays? | Usually not | Yes — unless task stops early |
| Navigation | Hierarchical | Linear |
| Main usability benefit | Learnability | Simplicity |

## Article 2: Information Scent

NNG | January 31, 2020 | https://www.nngroup.com/articles/information-scent/

**Summary:** Users choose links with the highest information scent — a combination of cues from link labels, surrounding context, and prior experience.

### What Is Information Scent?

Information scent represents the user's imperfect estimate of the value that a source will deliver, derived from a representation of the source. The concept is relative — the same link has different scent depending on what users seek.

### What Makes Up Information Scent

Two major components:

**What the user sees:**
- The link label — most critical; should be clear and self-explanatory
- Content accompanying the link — summary text and images augment link scent
- Context surrounding links — surrounding content influences link perception

**What the user knows:**
- Brand familiarity and trust
- Domain familiarity

### Key Principles for Helping Users Find Information

1. Use clear, specific link labels — avoid jargon and obscure terminology
2. Provide descriptive summary text that clarifies link content
3. Select representative images that accurately exemplify categories
4. Supply sufficient context early on landing pages to guide user expectations
5. Ensure content matches link promises to maintain trust

### Why Clickbait Doesn't Work Long-Term

Manipulating information scent through misleading titles attracts initial clicks but erodes trust. Like the boy who cried wolf, users become skeptical of future relevant content. Delivering on promises preserves user trust for future engagement.
