actual datasets, not just commentary. This is the priority build queue for category c.

## The honest constraint
Unlike public data (a/b/d/e/f), category-c is governed by **commercial terms**: most
require ToS review, API keys, or paid subscriptions, and the project policy
(`DATA_SOURCES.md`, category 4) needs **explicit PO approval** per source. So this map
is a *menu*, not a build queue — each ○/🔒 is a go/no-go (cost + legal), not an
automatic ingest. The free-and-clear ones (GPW, Stooq, OLiS, Box Office, 90minut,
e-petrol, CenyRolnicze, RCN, Gemius headline, BIK reports) build like any other source.
