# P14.1 Requirements Doc Recipe — Template Dashboard

## 1. Goals & Context
**Purpose**: This dashboard serves as the "Golden Reference" for the Open Reporting platform. It is designed to showcase every supported visual component, layout pattern, and data integration method.
**Audience**: Internal developers, PO, and stakeholders.
**Business Question**: "What are the standard visual and data patterns available in the Open Reporting platform, and how do they look with real-world data structures?"

## 2. Primary KPIs (Reference Metrics)
To demonstrate versatility, we use a set of generic but functionally distinct measures:
- **Measure A (Standard Value)**: Positive value (approx 45-55 range). Used for basic bars and lines.
- **Measure B (Secondary Value)**: Positive value (~5% higher than A). Used for combo charts and comparison.
- **Measure C (Percentage/Rate)**: Value expressed as a percentage. Used for %-stacked charts and rate-of-change.
- **Measure D (Small Value/Count)**: Small positive value. Used for bubble sizes and counts.
- **Measure E (Diverging)**: Value that varies between positive and negative. Used for waterfall and diverging charts.

## 3. Analytical Angles
The template must demonstrate the following 5 moves:
1. **Longitudinal Trend**: Change of Measure A/B/C over years (2018-2024).
2. **Categorical Comparison**: Measure A vs Categories (Cat A-E).
3. **Geographic Distribution**: Map-based views of Measure A across 12 European regions.
4. **Composition Analysis**: Part-to-whole breakdown using stacked columns and treemaps.
5. **Correlation/Distribution**: X/Y relationship (Scatter) and frequency distribution (Histogram/Boxplot).

## 4. Benchmarks & Context
- **Reference Line**: A static target (e.g., 50.0) to demonstrate reference lines in line charts.
- **Peer Groups**: 3 synthetic groups (Group A, B, C) to demonstrate clustered-stacked visuals.
- **Time Anchor**: Years 2018-2024.

## 5. Aggregation Rules
- **Category Axis**: Mean aggregation of measures.
- **Time Axis**: Mean aggregation + Cumulative Sum + Percentage Change.
- **Geo Axis**: Direct value mapping to ISO-3 codes.

## 6. Acceptance Criteria
- [ ] All 30+ visual components from the library are rendered.
- [ ] All charts use the "Nordic" theme (no hardcoded colors).
- [ ] All labels and titles are in Polish.
- [ ] Source attribution is visible in the footer.
- [ ] Layout follows the "Paper on Table" standard (cards on grey background).
