# P07.1 Semantic Model Data Logic — Template Dashboard

## 1. dbt Model Implementation

### Silver Layer: `curated.template_silver`
```sql
{{ config(materialized='view') }}

SELECT
    dim_year,
    dim_category,
    dim_iso3,
    AVG(val_a) AS val_a,
    AVG(val_b) AS val_b,
    AVG(val_c) AS val_c,
    AVG(val_d) AS val_d,
    AVG(val_e) AS val_e
FROM raw.template_data
GROUP BY dim_year, dim_category, dim_iso3
```

### Gold Layer: `curated.mart_template`
```sql
{{ config(materialized='incremental', unique_key='concat_key') }}

SELECT
    dim_year,
    dim_category,
    dim_iso3,
    AVG(val_a) AS val_a,
    AVG(val_b) AS val_b,
    AVG(val_c) AS val_c,
    AVG(val_d) AS val_d,
    AVG(val_e) AS val_e,
    -- Derived measures
    AVG(val_a) * 1.05 AS val_b, -- Simulated secondary value
    AVG(val_c) * 100 AS val_c_pct, -- Percentage conversion
    SUM(val_d) AS val_d_count, -- Cumulative count
    (MAX(val_e) - MIN(val_e)) AS val_e_range, -- Diverging range
    -- Aggregation helpers
    COUNT(*) AS sample_size,
    STDDEV(val_a) AS val_a_stddev,
    PERCENTILE_CONT(0.5) WITHIN GROUP (ORDER BY val_a) AS val_a_median,
    -- Dimension keys
    CONCAT(dim_year, '-', dim_category, '-', dim_iso3) AS concat_key
FROM {{ ref('template_silver') }}
{% if is_incremental() %}
    WHERE dim_year > (SELECT MAX(dim_year) FROM {{ this }})
{% endif %}
GROUP BY dim_year, dim_category, dim_iso3
```

## 2. Measure Definitions

| Measure ID | Name (Polish) | Name (English) | Type | Format | Aggregation |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **val_a** | Wartość Referencyjna A | Reference Value A | FLOAT | `#,##0.0` | AVG |
| **val_b** | Wartość Referencyjna B | Reference Value B | FLOAT | `#,##0.0` | AVG |
| **val_c** | Wskaźnik Procentowy C | Percentage Rate C | PERCENT | `0,0%` | AVG |
| **val_d** | Wartość Liczbowa D | Count D | INTEGER | `# ###` | SUM |
| **val_e** | Wartość Divergująca E | Diverging Value E | FLOAT | `+#,##0.0;-#,##0.0;0` | AVG |

## 3. Dimension References

| Dimension | Type | Polish Label | English Label |
| :--- | :--- | :--- | :--- |
| `dim_year` | TIME | Rok | Year |
| `dim_category` | CATEGORY | Kategoria | Category |
| `dim_iso3` | GEO | Kod Kraju (ISO-3) | Country Code (ISO-3) |

## 4. Join Logic
- Primary Key: `CONCAT(dim_year, '-', dim_category, '-', dim_iso3)`
- No joins required (single-source mart).
- All dimensions are self-contained.

## 5. Data Quality Checks
- `not_null_proportion: val_a: 1.0`
- `not_null_proportion: dim_year: 1.0`
- `dbt_utils.recency: dim_year: 3d`
