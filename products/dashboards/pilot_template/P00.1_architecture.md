# P00.1 System Architecture Blueprint — Template Dashboard

## 1. Data Flow Mapping
This dashboard follows the Medallion Architecture to demonstrate the full pipeline:
`raw.template_data` (Bronze) $\rightarrow$ `curated.template_silver` (Silver) $\rightarrow$ `curated.mart_template` (Gold)

### Layer Definitions
- **Bronze (Raw)**: `raw.template_data`. Append-only table containing the raw daily/yearly snapshots.
- **Silver (Curated)**: `curated.template_silver`. Cleaned, typed, and deduplicated data. This layer provides the base `dim_year`, `dim_category`, `dim_period`, and `dim_iso3` dimensions.
- **Gold (Mart)**: `curated.mart_template`. A highly aggregated a-priori view designed specifically for the Template Dashboard. It contains pre-calculated means and sums to ensure sub-second load times.

## 2. Column Mapping
To support the Reference Metrics (A-E), the following columns are required:

| Measure | Source Column | Type | Grain | Note |
| :--- | :--- | :--- | :--- | :--- |
| **Measure A** | `val_a` | FLOAT | Year/Cat/Geo | Standard Value |
| **Measure B** | `val_b` | FLOAT | Year/Cat/Geo | Secondary Value |
| **Measure C** | `val_c` | FLOAT | Year/Cat/Geo | Percentage/Rate |
| **Measure D** | `val_d` | FLOAT | Year/Cat/Geo | Small Value/Count |
| **Measure E** | `val_e` | FLOAT | Year/Cat/Geo | Diverging Value |
| **Geo** | `dim_iso3` | VARCHAR | Country | ISO-3 code |
| **Time** | `dim_year` | INT | Year | 2018-2024 |
| **Cat** | `dim_category` | VARCHAR | Category | Cat A-E |

## 3. Aggregation Rules
The `curated.mart_template` will apply the following logic:
- **Time-Series**: `AVG(val_*)` grouped by `dim_year`.
- **Categorical**: `AVG(val_*)` grouped by `dim_category`.
- **Geographic**: `AVG(val_*)` grouped by `dim_iso3`.
- **Special**: `SUM(val_a)` for cumulative views; `(val_a_current - val_a_prior) / val_a_prior` for % change.

## 4. Dependency Mapping
The following upstream dependencies are required:
- `raw.template_data` $\rightarrow$ `curated.template_silver` (via dbt `stg_template.sql`)
- `curated.template_silver` $\rightarrow$ `curated.mart_template` (via dbt `mart_template.sql`)
- `curated.mart_template` $\rightarrow$ `app.py` (via `data.py` loaders)
