## 2. Data Mapping (Chart → Measure)

Each component is wired to a specific measure from the Semantic Layer (P07.1):

| Component | Input Data (from mart_template) | Axis Mapping |
| :--- | :--- | :--- |
| `line()` | `val_a`, `dim_year` | x=year, y=value |
| `area()` | `val_b`, `dim_year` | x=year, y=value |
| `clustered_column()` | `val_a, val_b, val_c`, `dim_category` | x=category, y=value |
| `choropleth_map()` | `val_a`, `dim_iso3` | locations=iso3, z=value |
| `treemap()` | `val_a`, `dim_category` | labels=category, values=value |
| `histogram()` | `val_a` | x=value |
| `scatter_bubble()` | `val_a, val_b`, `val_d` | x=val_a, y=val_b, size=val_d |
