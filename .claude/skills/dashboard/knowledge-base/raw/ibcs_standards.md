## What IBCS Is
IBCS represents "practical proposals for designing business communication, available for free use under a Creative Commons license." The standards optimize reports, presentations, and dashboards through three dimensions: conceptual design, visual perception, and semantic notation.

The IBCS Association, a nonprofit, maintains and develops standards through public consultation. Version 1.0 launched in 2015, followed by 1.1 (2017) and 1.2 (2021). As of June 2024, membership reached 12,384 members from 139 countries.

In July 2024, ISO/AWI 24896 "Standard notation for business reports" began, with experts from 12 countries, based on IBCS proposals.

## The SUCCESS Framework

Seven core principles:

| Letter | Principle | Rule type | Meaning |
|--------|-----------|-----------|---------|
| S | **SAY** | Conceptual | Convey a clear, unambiguous message |
| U | **UNIFY** | Semantic | Apply consistent semantic notation |
| C | **CONDENSE** | Perceptual | Increase information density |
| C | **CHECK** | Perceptual | Ensure visual integrity |
| E | **EXPRESS** | Perceptual | Choose the proper visualization |
| S | **SIMPLIFY** | Perceptual | Avoid clutter; leave out the superfluous |
| S | **STRUCTURE** | Conceptual | Organize content clearly and logically |

## Three Pillars

**Conceptual Rules** (SAY + STRUCTURE)
- Draw from Barbara Minto's pyramid principle — clear content transmission via storytelling and logical flow
- Central message stated prominently (title or first line of chart/report)
- Read order: left to right, top to bottom — most important information top-left

**Perceptual Rules** (EXPRESS, CHECK, CONDENSE, SIMPLIFY)
- Built on William Playfair, Edward Tufte, and Stephen Few
- Grounded in visual perception science
- Chart type selection based on what the data is saying, not aesthetic preference

**Semantic Rules** (UNIFY)
- IBCS Notation: standardized terminology, abbreviations, number formats, descriptive texts, dimensions, analyses, indicators
- Led by Rolf Hichert and the IBCS Association

## Scenario Notation (Semantic Rules)

IBCS distinguishes data by scenario type using fill styles:
- **Actuals (AC):** Solid dark fill
- **Previous year (PY):** Solid lighter fill
- **Plan (PL):** Outlined/hollow (fictional/target data)
- **Forecast (FC):** Hatched fill (between plan and actual)

This ensures that audiences can immediately distinguish measured data from planned or projected data without reading labels.

## Chart Type Standards (EXPRESS)

- **Time series → column or line chart** (not pie)
- **Structure/composition → stacked bar or column**
- **Variance analysis → waterfall chart** — bridge between base and final value
- **Ranking → horizontal bar, sorted descending**
- **Correlation → scatter plot**
- **Part-to-whole → stacked bar** (not pie — pie charts are discouraged)

## KPI and Scorecard Standards

- Most important KPIs: top-left position
- Every KPI must include an absolute variance (Δ) and relative variance (Δ%) vs. reference scenario (plan or prior year)
- Use consistent notation: Δ for absolute difference, Δ% for relative difference
- Scale indicators (K, M, B) applied consistently across all measures on same page

## Dashboard Structure
- Reports and dashboards organized so the central message is immediately visible
- Structure: Message → Dimensions → Details (top to bottom)
- Semantic consistency: same entity always represented by same color, same notation, same abbreviation across all pages and reports
