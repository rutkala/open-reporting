## Core Principles

**1. Effective Information Presentation**
Present data tailored to the end user's analytics capability and decision-making needs. Select the appropriate dashboard type—strategic, operational, analytical, informational, or contextual—based on audience requirements.

**2. Visual Consistency**
Maintain uniform typography, colors, and graphic elements throughout. Limit the number and size of fonts. Ensure colors are consistent throughout. A common mistake: using identical colors for different fields, which creates confusion.

**3. Efficient Interactions**
Remove superfluous visualizations and ensure interactions logically align with user workflows. "Show only the data the user needs to make the decisions they need to make."

**4. Effective Use of Language**
Employ clear, descriptive labeling rather than assuming user knowledge. Include brief expanded descriptions beneath headers.

**5. Minimize Cognitive Load**
Limit visual elements, actions, and options to prevent mental strain. People become overwhelmed by excessive choices, leading to dashboard avoidance.

**6. Make It Responsive**
Design dashboards to function across all devices and screen sizes.

**7. Design for Speed**
Prioritize performance through visualization reduction, data filtering, and load-on-demand widgets. Slow loading discourages user engagement.

**8. Augment with AI**
Natural language query and automated anomaly detection to surface insights automatically.

**9. Keep Dashboards Updated**
Schedule regular data refreshes; periodically audit metrics for continued relevance.

**10. Maintain Data Accuracy**
Pull from clean, authenticated sources; validate transformations using subject matter expert review.

## Layout & Visual Hierarchy
Organize information top-to-bottom with most important metrics first. Logical row-and-column structures for clarity. Avoid information overload by spacing elements appropriately.

## Chart & KPI Selection
Recommended range: 5–9 visuals per dashboard. 5–9 KPIs maximum to prevent cognitive overload.
Line and area charts excel for trend visualization. Use tables for precise values; charts for pattern identification.

## The Five-Second Rule
Users should grasp the main insight within five seconds of viewing the dashboard. If this fails, reassess layout, hierarchy, or clarity.
